# Shopify-Theme sleepzlab.com — Arbeitskopie

Ausschnitt des Themes "Kopie von SleepzLab - Original"
(gid://shopify/OnlineStoreTheme/206470414678), gezogen ueber die
Shopify Admin API am 08.09.2026.

Zweck: nachvollziehbare Optimierung der Produktseite /products/somaband.
Hier liegen nur die Dateien, die fuer die Ladezeit dieser Seite zaehlen —
nicht das komplette Theme.

Basis-Theme: Shopify **Horizon** (block-basiert, ES-Module, section-renderer).
Die Produktseiten sind komplett von Hand gebaut; Horizons eigene
Produkt-Section `product-information` ist in allen Produkt-Templates
auf `disabled` gesetzt.

Der erste Commit ist der **unveraenderte** Stand aus dem Shop.
